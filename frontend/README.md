# Galli Agent Frontend

The frontend for Galli Agent, built with React, TypeScript, and Vite.

The application provides an interactive dashboard for analyzing delivery requests, visualizing routes, and presenting operational intelligence generated by the backend. It communicates with the Go backend through REST APIs to display deterministic delivery decisions alongside AI-assisted mission planning, operational explanations, and safety reflections.

---

## Features

- Delivery request submission
- Interactive route visualization
- Real-time delivery analysis
- Operational summary dashboard
- AI mission planning
- AI operational explanations
- AI safety reflections
- Responsive user interface
- Modern component-based architecture

---

## User Interface

The web application provides a unified dashboard for logistics analysis, allowing users to:

- Configure delivery requests.
- Visualize routes on an interactive map.
- Review weather, traffic, and operational risk factors.
- Evaluate delivery partner recommendations.
- Inspect deterministic delivery decisions generated by the multi-agent engine.
- Review AI-generated mission plans, operational explanations, and safety reflections through a clean, responsive interface.

## Getting Started

### Clone the repository

```bash
git clone https://github.com/Gautam2920/galli-agent.git
cd galli-agent/frontend
```

### Install dependencies

```bash
npm install
```

### Configure environment variables

Create a `.env` file in the frontend directory.

Example:

```env
VITE_API_BASE_URL=http://localhost:8080
```

Update the API URL if your backend is running on a different host.

---

### Run the development server

```bash
npm run dev
```

The application will be available at:

```text
http://localhost:5173
```

---

## Building for Production

Create a production build.

```bash
npm run build
```

Preview the production build locally.

```bash
npm run preview
```

## Backend Integration

The frontend communicates with the Go backend through REST APIs.

The backend is responsible for:

- Delivery analysis
- Route intelligence
- Weather analysis
- Traffic analysis
- Operational risk assessment
- Delivery partner evaluation
- AI-generated mission planning
- AI-generated operational explanations
- AI-generated safety reflections
